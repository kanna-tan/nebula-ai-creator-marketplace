## 🌌 Overview

Generative AI has unleashed a new creative class—AI directors, prompt architects, virtual fashion creators, and procedural animators. However, legacy freelance platforms (like Upwork or Fiverr) were designed for static raster graphics and manual keyframing. They lack the tools to:
- Inspect multi-model ComfyUI pipelines and reproducible node graphs.
- Verify generation seeds, samplers, and prompt architectures.
- Enforce character identity consistency across multi-scene commercial campaigns.
- Indemnify enterprise brands against model training copyright risks.

**Nebula** solves this trust gap by introducing an AI-native marketplace architecture with verified toolchains, reproducible workflow inspection, escrow milestone releases, and an AI-powered brief studio.

## 🚀 Core Features

### 1. Creator Profiles & AI Portfolios (30% Evaluation Weight)
- **Generative Stack Provenance**: Displays tools and models used (`Flux.1 Pro`, `Runway Gen-3`, `Midjourney v6.1`, `ComfyUI`, `Kling 1.5`, `Luma Dream Machine`, `Topaz Video AI 5`, `ElevenLabs`).
- **Workflow Pipeline Breakdown**: Step-by-step node breakdown from base latent and LoRA character injection to temporal interpolation and 4K mastering.
- **Prompt Architecture & Negative Tokens**: One-click positive prompt copying and negative token pruning inspection.
- **Seed & Sampler Metadata**: Verifiable seed numbers, CFG scales, step counts, and samplers (`Euler a`, `DPM++ 2M`).
- **Media Previews**: Simulated playable video player with audio controls and format labels.

### 2. Brand & Agency Creative Briefs (20% Evaluation Weight)
- **Structured Brief Publisher**: Covers Campaign Title, Content Type, Style/Aesthetic, Multi-Platform Aspect Ratios (`16:9 Cinema 4K` + `9:16 Social Cutdown`), and Budgets in `₹`.
- **Commercial-Use & Legal Terms**: Explicit stipulations for Full Global Buyouts, 2-Year Digital Rights, raw seed & ComfyUI workflow JSON handoff, and anti-model-training warranties.
- **Proposal Submission Engine**: Creators submit bids with custom pitch messages, proposed AI pipelines, and turnaround estimates.

### 3. Creator Search & Multi-Attribute Filtering (25% Evaluation Weight)
- **Real-Time Search**: Instant search across creator names, tools (`Flux.1`, `Runway`, `ComfyUI`), skills, or styles (`Celestial`, `Haute Couture`).
- **Granular Filters**: Filter by Medium (Video, Animation, Stills, 3D), AI Model, Creative Specialization, and Verification status.
- **Sorting Options**: Sort by Highest Rated, Most Completed Jobs, or Starting Project Rate.
- **Sensible Empty State**: Helpful suggestions and one-click filter reset when queries yield zero matches.

### 4. Bonus Feature: Creator Verification Signals (+5–10 Points)
- 🛡️ **Verified AI Workflow**: Tested ComfyUI node graphs for reproducible seed generation.
- ⚡ **Verified Tool API Access**: Validated enterprise subscriptions to Runway, Midjourney, and Flux.
- 🎯 **Identity Consistency Benchmark**: Certified 10-shot multi-angle facial and character consistency (e.g., *99.4% Identity Match*).
- 📜 **Commercial IP Warranty**: Creators provide warranties of commercially cleared base models.

### 5. Bonus Feature: AI-Assisted Brief Studio (+5–10 Points)
- Translates one-sentence rough ideas (e.g., *"A mystical ethereal perfume commercial in a floating stardust galaxy with cream silk fluid ribbons"*) into comprehensive 5-point production briefs.
- Generates polished campaign titles, tool recommendations, 9:16 & 16:9 aspect ratios, commercial IP clauses, and milestone plans.
- One-click **"Publish to Marketplace"** immediately lists the brief for creator proposals.

### 6. Active Engagements & Escrow Delivery Pipeline
- Lifecycle tracking: *Discovery &rarr; Proposal Accepted &rarr; Keyframe Seed Approval &rarr; Motion Generation Review &rarr; 4K Master & IP Release*.
- **Submission Artifacts Vault**: Direct access to ProRes video renders, `.json` ComfyUI blueprints, and countersigned commercial rights certificates.
- **Milestone Escrow Sign-Off**: Milestone approvals with confetti celebration.

### 7. Built-in Pitch Deck & Data Model Spec
- **Pitch Slides Deck**: 7 interactive slides with keyboard navigation (Arrow keys / Space) covering vision, market problem, 4-pillar solution, trust signals, brief studio, business model, and evaluation alignment.
- **Data Model Architecture**: Formal JSON schema viewer detailing `CreatorProfile`, `PortfolioItem`, `CreativeBrief`, and `EngagementWorkflow`.

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or newer)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/kannanekkanti-glitch/nebula-ai-creator-marketplace.git

# Navigate to project directory
cd nebula-ai-creator-marketplace

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build & Preview

```bash
# Build for production
npm run build

# Preview production build locally
npm run preview
```
